# Calidad en la preparación de habitaciones · Hotel Río Blanco

Presentación final del curso **Gestión de la Calidad** (Ingeniería Industrial, UPAO).

Autores: Alarcón Chávez, Jopse · Olivos Reyes, Jhon
Docente: Jimmy Nicola

## Contenido

| Archivo | Qué es |
| --- | --- |
| `index.html` | Presentación con gráficos animados (flechas para avanzar, `F` pantalla completa, `S` notas del expositor) |
| `dashboard.html` | Dashboard interactivo: filtra por tipo de día o con un clic en la gráfica p |
| `flujograma.html` | Flujograma animado del proceso actual y del propuesto |
| `anim/` | Gráficos animados que usa la presentación |
| `lib/` | reveal.js 5.1.0 y d3 7.9.0, incluidos para que funcione sin conexión |

## Cómo verlo

- **En línea:** con GitHub Pages activado (rama `main`, carpeta raíz).
- **Sin internet:** descarga el repositorio y abre `index.html` en el navegador.

Caso de estudio académico.
